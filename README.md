# 📉 Customer Churn Data Analysis

## 🔍 Project Overview
Customer churn is a major challenge for businesses, as acquiring new customers is often more expensive than retaining existing ones.  
This project analyzes customer behavior and identifies key factors that contribute to customer churn using **Power BI**.

The dashboard provides clear, interactive insights to help businesses understand **why customers leave**, **which customer segments are at risk**, and **how retention strategies can be improved**.

---

## 🎯 Business Problem
Businesses face difficulty in:
- Identifying customers likely to churn
- Understanding churn patterns across demographics and services
- Reducing revenue loss caused by customer attrition
- Designing data-driven customer retention strategies

This project addresses these challenges through data visualization and analysis.

---

## 🛠 Tools & Technologies Used
- **Power BI Desktop**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Excel / CSV** – Data source

---

## 📌 Key Features
- Churn vs Non-Churn customer analysis
- Churn rate KPI and customer count metrics
- Demographic analysis (Gender, Senior Citizen, etc.)
- Service usage analysis (Internet, Contract Type, Payment Method)
- Interactive slicers for dynamic exploration
- Bookmarks for storytelling and presentation

---

## 📊 Key Insights
- Identifies customer segments with **high churn risk**
- Shows impact of **contract type and payment method** on churn
- Highlights services associated with higher churn
- Helps stakeholders focus on **retention strategies**
